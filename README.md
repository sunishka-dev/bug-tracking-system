# Bug Tracking System

Track software issues from report to resolution.

## Features
- Create and delete bug reports
- Set Low, Medium, or High priority
- Track Open, In Progress, and Resolved states
- Filter reports by status
- View dashboard summary counts

## Technology
- Python 3
- Flask
- SQLite
- HTML and CSS

## Run locally
1. Install Python 3.9 or later.
2. Open a terminal in this project folder.
3. Create a virtual environment: `python -m venv venv`
4. Activate it: Windows `venv\\Scripts\\activate` or macOS/Linux `source venv/bin/activate`
5. Install dependencies: `pip install -r requirements.txt`
6. Run: `python app.py`
7. Visit `http://127.0.0.1:5000`.

The SQLite database is created automatically on first run.
